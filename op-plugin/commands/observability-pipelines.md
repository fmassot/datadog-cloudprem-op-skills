# Observability Pipelines Deployment Assistant

Ask the user what they need help with:

- **Deploying OP** - Which platform? (EC2 / Fargate / EKS / AKS / GKE / vanilla K8s)
- **Creating pipelines** - Using the OP API to configure sources, transforms, and destinations
- **Scaling** - Manual scaling or autoscaling setup
- **Debugging** - What issue are they experiencing?
- **Monitoring** - Setting up metrics and alerts
- **Upgrades** - Version upgrades or configuration changes
- **General questions** - Architecture, sizing, best practices

Then use the observability-pipelines skill to provide platform-specific guidance.
